## Tasks Performed

### Task 1: Converting Object to JSON Text

### Task 2: Converting JSON Text to Object
Stored JSON text containing city and pin information in a variable. Used `JSON.parse()` to convert it into a JavaScript object and printed the city.

### Task 3: Handling Invalid JSON
Stored invalid JSON text in a string variable. Used `try` and `catch` with `JSON.parse()` to handle the error and display an appropriate message.
